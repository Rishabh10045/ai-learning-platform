## How it was produced

All 116 compiled and exited 0. No SQL fixture exists for any day, so no SQL was run.
- **Rendered app:** `checks/integrated.mjs` renders all 56 sessions at 1280 and 320 px (title, worked example, interview answers, no overflow, no console errors), and `checks/pr-a-walk.mjs` walks Days 1, 9, 17, 26, 35, 44, 46 and 56 (plan, learn, practice, revision × 1366/390 px × light/dark). Both passed on this branch.
- **Questions:** "Quiz" is the scored self-check (count × options). "Checks" is the lettered concept checks inside the notes.
- **Estimate vs slot:** core estimate = 12-minute revision (from Day 2) + required, non-stretch practice minutes; stretch = optional stretch items. Slot = default budget (weekday 120, weekend 390 = 120 core + 270 stretch).
